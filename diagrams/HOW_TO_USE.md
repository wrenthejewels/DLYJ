# Diagram Files

## Quick start

### Mermaid files (recommended import path)
1. Open [Excalidraw](https://excalidraw.com)
2. Click the **library icon** (top-left hamburger or sidebar) → **Mermaid to Excalidraw**
3. Paste the contents of any `.mmd` file
4. Click **Insert into Canvas**
5. All shapes are now editable Excalidraw elements — rearrange, restyle, annotate freely

### Excalidraw file (direct open)
1. Open Excalidraw → **Open** → select `model_evolution_starter.excalidraw`
2. Already laid out as a vertical timeline — drag to reposition, double-click to edit text

## Files

| File | Content | Best for |
|------|---------|----------|
| `model_evolution.mmd` | 5-phase build history timeline | "How I built this" page |
| `scoring_pipeline.mmd` | Full scoring flow: input → task → cluster → wave → fate | Methodology page |
| `data_source_map.mmd` | Data sources → engine layer mapping | "How I built this" or methodology |
| `model_evolution_starter.excalidraw` | Pre-positioned evolution timeline | Direct editing in Excalidraw |

## Tips
- After Mermaid import, Excalidraw auto-generates all boxes/arrows but the layout may need manual adjustment
- Use Excalidraw's **sticky notes** to add your own annotations on top
- Export as SVG or PNG for embedding in the site
